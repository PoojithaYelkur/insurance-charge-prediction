# Insurance Charge Prediction

## Overview

This project explores a medical insurance dataset and prepares the data
for predicting insurance charges.

## Dataset

The dataset contains 1,338 records and 7 columns:

- age
- sex
- bmi
- children
- smoker
- region
- charges

## Workflow

1. Exploratory Data Analysis
2. Missing-value analysis
3. Duplicate removal
4. Categorical encoding
5. BMI feature engineering
6. Feature standardization
7. Pearson correlation analysis
8. Chi-square feature selection

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Scikit-learn

## Target Variable

`charges`

## Current Status

The notebook currently focuses on EDA, preprocessing,
feature engineering and feature selection.
